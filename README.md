A browser-based version of the classic Etch-A-Sketch toy, built from scratch using Vanilla JavaScript. This project focuses on DOM manipulation and dynamic grid generation.

## ✨ Features
- **Dynamic Grid:** Ability to resize the drawing board (up to 100x100).
- **Interactive Drawing:** Hover-based interaction to fill the grid.
- **Clean UI:** Minimalist and responsive design.

## 🛠️ Key Learnings
This project was a major milestone in my journey through **The Odin Project**. I deepened my understanding of:
- **DOM Manipulation:** Managing elements without libraries.
- **Event Listeners:** Handling user hover and click interactions.
- **Logic:** Implementing calculations for dynamic grid resizing.

## 🚀 How to run locally
1. Clone this repository: 
   `git clone https://github.com/LucasAzevedoTheDev/etch-a-sketch.git`
2. Open `index.html` in your browser.
